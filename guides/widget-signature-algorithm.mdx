This page describes the signature algorithm used by the **[Holdstation Pay Widget](/guides/widget-overview)** only. It produces the value you pass as the `signature` query parameter in the widget's iframe URL, alongside your partner app key (`pk`). See [Widget Configuration](/guides/widget-configuration) for the full parameter list.

<Warning>
  **This is not the signing scheme used by the Holdstation Pay API.** Server-to-server calls to `/partners/*` endpoints use a different algorithm with its own headers — see [Request Signing](/guides/partner-authentication-signed-api/overview). The two are not interchangeable: the widget signs an underscore-joined, lowercased string of widget parameters, while the API signs the query string, request body, and a timestamp.
</Warning>

## Basic Rules

1. The signature is generated using the **Ed25519** cryptographic signature scheme on a formatted string.
2. All fields are separated by underscore `_`, even if the field is empty.
3. All sign message characters are **lowercase**.

## Sign Message Format

The fields below are the widget URL parameters for each flow, joined in this exact order.

### Onramp (Buy)

```
{amount}_{callback}_{chain_id}_{currency}_{recipient}_{reference_no}_{token_address}
```

### Offramp (Sell)

```
{amount}_{callback}_{chain_id}_{currency}_{bank_bin_code}_{bank_account_number}_{token_address}
```

When `refund_address` is set, it is appended to the end:

```
{amount}_{callback}_{chain_id}_{currency}_{bank_bin_code}_{bank_account_number}_{token_address}_{refund_address}
```

<Note>
  `refund_address` is optional. Omit the trailing field entirely when it is not set — do not append an empty segment.
</Note>

## Example

<CodeGroup>
```go Go
package main

import (
    "crypto/ed25519"
    "encoding/base64"
    "strings"
)

var sampleSignKey = "Qd2XliU6/I6YD3OELdeBQ57z6Q9/OHGBTjCNVLB8s/1KpvoU6aiuuBTgQ72IW/yA0aYYnfbCX31zhJKsPnRE5Q=="

func sign(msg string) string {
    signKey, _ := base64.StdEncoding.DecodeString(sampleSignKey)
    signature := ed25519.Sign(ed25519.PrivateKey(signKey), []byte(msg))
    return base64.StdEncoding.EncodeToString(signature)
}

func main() {
    params := []string{
        "1000000",  // amount
        "",         // callback
        "56",       // chain_id
        "",         // currency
        "0x0000000000000000000000000000000000000000", // recipient
        "rmtbPVEKwLzz27Qs51Jio",                      // reference_no
        "0x55d398326f99059ff775485246999027b3197955", // token_address
    }
    signMessage := strings.Join(params, "_")
    signMessage = strings.ToLower(signMessage)
    signature := sign(signMessage)
    println("Message:", signMessage)
    println("Signature:", signature)
}
```
</CodeGroup>

### Output

```
Message: 1000000__56__0x0000000000000000000000000000000000000000_rmtbpvekwlzz27qs51jio_0x55d398326f99059ff775485246999027b3197955
Signature: +EEox+pWc3dC854Av3eIzLbGthud0p2/xrosE9tcOHvLEji8uajyJzDwV95IFClhmCnCqPXtjQsZmYS0jrtgBw==
```

<Warning>
  Remember to convert the entire sign message to **lowercase** before signing.
</Warning>

## Using the Signature

Pass the result as the `signature` query parameter on the widget iframe URL, together with your partner app key:

```
https://pay.capybera.xyz/?pk=YOUR_PARTNER_APP_KEY&signature=YOUR_SIGNATURE&amount=1000000&chain_id=56&...
```

See [Widget Configuration](/guides/widget-configuration) for every supported parameter, and [Partner Integration](/guides/partner-integration) for attributing widget transactions to your platform.
