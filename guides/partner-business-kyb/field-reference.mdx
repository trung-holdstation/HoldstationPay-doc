---
title: "Field Reference"
description: "Every field on a KYB submission — business details, persons, documents, and files."
---

The request body for [`POST /partners/kyb`](/api-reference/kyb/submit-kyb) is a single JSON object. **Every field below is mandatory** — the arrays `persons` and `documents` must be present, and Holdstation Pay validates each nested entry.

## Business Fields

| Field | Type | Required | Notes |
|---|---|---|---|
| `subject_type` | int enum | Yes | `1` = the partner itself, `2` = a merchant under the partner |
| `legal_name` | string | Yes | Registered company name |
| `registration_number` | string | Yes | Business registration number |
| `incorporation_country` | string | Yes | ISO 3166-1 alpha-2 country code, e.g. `VN` |
| `incorporation_date` | string | Yes | ISO `YYYY-MM-DD` |
| `address` | string | Yes | Registered business address |
| `email` | string | Yes | Business email |
| `phone` | string | Yes | Business phone number |
| `website` | string | Yes | Business website |
| `nature_of_business` | string | Yes | Description of the business activity |
| `geographic_scope` | string[] | Yes | ISO 3166-1 alpha-2 codes the business operates in |
| `persons` | object[] | Yes | Legal representatives and directors — see [Persons](#persons) |
| `documents` | object[] | Yes | Company documents, types `1`–`9` — see [Documents](#documents) |

<Note>
  Do not send an `id`. The record id is generated by Holdstation Pay and returned in the response.
</Note>

## Persons

Each entry in `persons[]` is one legal representative or director.

| Field | Type | Required | Notes |
|---|---|---|---|
| `role` | int enum | Yes | `1` = Legal representative, `2` = Director |
| `name` | string | Yes | Full name |
| `date_of_birth` | string | Yes | ISO `YYYY-MM-DD` |
| `email` | string | Yes | Email |
| `phone` | string | Yes | Phone number |
| `address` | string | Yes | Residential address |
| `id_number` | string | Yes | Identity document number. Encrypted at rest. |
| `id_type` | int enum | Yes | `1` = Citizen ID, `2` = Passport, `3` = License |
| `sex` | int enum | Yes | `1` = Male, `2` = Female, `3` = Other |
| `nationality` | string | Yes | Nationality |
| `date_of_issue` | string | Yes | ISO `YYYY-MM-DD` |
| `date_of_expiry` | string | Yes | ISO `YYYY-MM-DD` |
| `documents` | object[] | Yes | Personal identity documents, types `10` or `11` only |

## Documents

The same document object is used in both `documents[]` and `persons[].documents[]` — only the accepted `type` values differ.

| Field | Type | Required | Notes |
|---|---|---|---|
| `type` | int enum | Yes | See [Document Types](#document-types) |
| `document_number` | string | Yes | Must be present. Carries the licence number for type `4`; send an empty string for types that have no number. |
| `date_of_issue` | string | Yes | ISO `YYYY-MM-DD` |
| `date_of_expiry` | string | Yes | ISO `YYYY-MM-DD` |
| `files` | object[] | Yes | Up to **10 files** per document — see [Files](#files) |

### Document Types

| Value | Type | Belongs in |
|---|---|---|
| `1` | Incorporation paper | `documents[]` |
| `2` | Business registration extract | `documents[]` |
| `3` | Nature and scope declaration | `documents[]` |
| `4` | Import/export licence | `documents[]` |
| `5` | Product images | `documents[]` |
| `9` | Other | `documents[]` |
| `10` | Passport | `persons[].documents[]` |
| `11` | Citizen ID | `persons[].documents[]` |

<Warning>
  Company documents accept types `1`–`9`; personal identity documents accept only `10` or `11`. Putting a type in the wrong array is a validation error.
</Warning>

## Files

| Field | Type | Required | Notes |
|---|---|---|---|
| `filename` | string | Yes | Original file name |
| `content_type` | string | Yes | `application/pdf`, `image/jpeg`, `image/png`, or `image/heic` |
| `data` | string | Yes | Base64-encoded file contents, max **10 MB** decoded |

See [Submitting Documents](/guides/partner-business-kyb/submitting-documents) for encoding rules and size limits.

## Response-Only Fields

[`GET /partners/kyb/{id}`](/api-reference/kyb/get-kyb) returns everything you submitted, plus:

| Field | Type | Notes |
|---|---|---|
| `id` | string | Server-generated record id |
| `partner_id` | string | The partner that owns the record |
| `status` | int enum | `1` = Pending, `2` = Approved, `3` = Rejected |
| `rejection_reason` | string | Set only when `status` is `3` |
| `submitted_at` | string | When the record was submitted |
| `reviewed_at` | string | `null` while the record is Pending |
| `created_at` | string | Record creation time |
| `updated_at` | string | Last modification time |

Uploaded files come back as **metadata only** — never as bytes:

| Field | Type | Notes |
|---|---|---|
| `file_ref` | string | Opaque stored-file reference |
| `filename` | string | Original file name |
| `content_type` | string | MIME type of the stored file |
| `size` | integer | Decoded size in bytes |
