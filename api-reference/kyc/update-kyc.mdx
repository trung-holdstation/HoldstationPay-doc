---
title: "Update Customer KYC"
api: "PUT https://pay-api.holdstation.com/partners/kycs/{id}"
description: "Update an existing partner customer KYC record."
---

Update an existing partner customer KYC record. Fails with `404 Not Found` if the id is unknown. KYC records cannot be deleted.

See the [Partner Customer KYC guide](/guides/partner-customer-kyc/overview) for the field reference.

## Authentication

<ParamField header="Partner-App-Key" type="string" required>
  Your partner app key.
</ParamField>

<ParamField header="X-HSPay-Signature" type="string" required>
  Base64-encoded Ed25519 signature of the sign data.
</ParamField>

<ParamField header="X-HSPay-Timestamp" type="string" required>
  Unix timestamp (seconds) of the request. Must be within 60 seconds of server time.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
  Partner-provided unique id of the customer KYC record to update.
</ParamField>

## Body Parameters

<Note>
  At least one of `email` or `phone` must be provided. `date_of_expiry` is optional. Every other body field is mandatory.
</Note>

<ParamField body="name" type="string" required>
  Full name.
</ParamField>

<ParamField body="email" type="string">
  Email. Required if `phone` is not provided.
</ParamField>

<ParamField body="phone" type="string">
  Phone number. Required if `email` is not provided.
</ParamField>

<ParamField body="address" type="string" required>
  Residential address.
</ParamField>

<ParamField body="id_number" type="string" required>
  Identity document number.
</ParamField>

<ParamField body="id_type" type="integer" required>
  `1` = Citizen ID, `2` = Passport, `3` = Driver License.
</ParamField>

<ParamField body="sex" type="integer" required>
  `1` = Male, `2` = Female, `3` = Other.
</ParamField>

<ParamField body="nationality" type="string" required>
  Nationality.
</ParamField>

<ParamField body="date_of_issue" type="string" required>
  Identity document issue date in ISO `YYYY-MM-DD` format.
</ParamField>

<ParamField body="date_of_expiry" type="string">
  Optional. Identity document expiry date in ISO `YYYY-MM-DD` format. Omit when the document does not expire.
</ParamField>

<ParamField body="id_front_img" type="object">
  Optional. Photo of the identity document front. `{ "content_type": "image/jpeg|image/png|image/heic", "data": "<base64>" }` — see [Images](/guides/partner-customer-kyc/kyc-management#images).
</ParamField>

<ParamField body="id_back_img" type="object">
  Optional. Photo of the identity document back. Same shape as `id_front_img`.
</ParamField>

<ParamField body="selfie_img" type="object">
  Optional. Selfie photo of the customer. Same shape as `id_front_img`.
</ParamField>

<Note>
  The three image fields are optional and independent — send any, all, or none. **An image you omit is left as it was stored** — an update never clears an image; sending one replaces the stored image and deletes the old one. Each is `content_type` (`image/jpeg`, `image/png`, or `image/heic`; **PDF is not accepted**) plus base64 `data`. There is no `filename`: the stored name comes from the field, so `selfie_img` is stored as `selfie_img.jpg`. Each image is capped at **10 MB decoded** and the whole body at **32 MB encoded**. See [Images](/guides/partner-customer-kyc/kyc-management#images).
</Note>
