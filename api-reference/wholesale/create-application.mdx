## Authentication

<ParamField header="Partner-App-Key" type="string" required>
  Your partner app key.
</ParamField>

<ParamField header="X-HSPay-Signature" type="string" required>
  Base64-encoded Ed25519 signature of the sign data.
</ParamField>

<ParamField header="X-HSPay-Timestamp" type="string" required>
  Unix timestamp (seconds) of the request. Must be within 60 seconds of server time.
</ParamField>

## Overview

Create a wholesale application for the authenticated user. This allows partners to apply for wholesale rates.

<ParamField body="default_rate" type="number" required>
  Optional default wholesale rate. For example, `0.01` for 1 percent. Pass `null` if not applicable.
</ParamField>

<RequestExample>
```json
{
  "default_rate": 0.01
}
```
</RequestExample>
