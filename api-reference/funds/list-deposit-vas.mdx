---
title: "List VND Deposit Accounts"
api: "GET https://pay-api.holdstation.com/partners/funds/deposit-vas"
description: "List the partner's VND deposit accounts."
---

Lists the partner's VND deposit accounts. A partner can hold several at once. Closed accounts are included — check `status` to tell them apart.

This is how you retrieve accounts you already hold: [Create VND Deposit Account](/api-reference/funds/create-deposit-va) opens a new one on every call, so use this endpoint rather than creating again.

See [Prefunding Offramp Flow → VND Deposit Accounts](/guides/partner-prefunding#vnd-deposit-accounts) for the workflow.

## Authentication

<ParamField header="Partner-App-Key" type="string" required>
  Your partner app key.
</ParamField>

<ParamField header="X-HSPay-Signature" type="string" required>
  Base64-encoded Ed25519 signature of the sign data.
</ParamField>

<ParamField header="X-HSPay-Timestamp" type="string" required>
  Unix timestamp (seconds) of the request. Must be within 60 seconds of server time.
</ParamField>

## Query Parameters

<ParamField query="status" type="integer">
  Only accounts with this status: `1` = ACTIVE, `2` = CLOSED.
</ParamField>

<ParamField query="page" type="integer">
  Page number. Default `1`.
</ParamField>

<ParamField query="page_size" type="integer">
  Results per page. Default `20`, max `100`.
</ParamField>
