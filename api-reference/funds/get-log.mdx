---
title: "Get Fund Log"
api: "GET https://pay-api.holdstation.com/partners/funds/logs/{fund_log_id}"
description: "Retrieve one fund transaction log by ID."
---

Returns one fund transaction log, in the same shape as an entry of [List Fund Logs](/api-reference/funds/list-logs).

This is the endpoint to call after a [Balance Change Webhook](/guides/webhooks/balance-change-webhook) event: the payload carries a `fund_log_id` but no metadata, so fetch the log here and read its [`metadata.source`](/api-reference/funds/list-logs#metadata) to learn what actually caused the change.

<Note>
  An ID that belongs to another partner returns `404`, the same as an unknown ID. A malformed `fund_log_id` returns `400`.
</Note>

## Authentication

<ParamField header="Partner-App-Key" type="string" required>
  Your partner app key.
</ParamField>

<ParamField header="X-HSPay-Signature" type="string" required>
  Base64-encoded Ed25519 signature of the sign data.
</ParamField>

<ParamField header="X-HSPay-Timestamp" type="string" required>
  Unix timestamp (seconds) of the request. Must be within 60 seconds of server time.
</ParamField>

## Path Parameters

<ParamField path="fund_log_id" type="integer" required>
  Fund log ID — the `fund_log_id` from the fund balance change webhook.
</ParamField>

## Response Fields

The `log` object has the same fields as an entry of [List Fund Logs](/api-reference/funds/list-logs#log-fields), including the [`metadata`](/api-reference/funds/list-logs#metadata) that explains the change.
