---
title: "List Fund Logs"
api: "GET https://pay-api.holdstation.com/partners/funds/logs"
description: "List fund transaction logs, with the metadata explaining what caused each balance change."
---

Lists the partner's fund transaction logs. Every balance change is recorded here — VND and crypto deposits, offramp withdrawals, crypto payouts, compensations, and stablecoin conversions.

`change_type` says whether the balance went up or down and broadly why; **`metadata.source` says what actually caused it**. The two are not interchangeable — see [Metadata](#metadata).

## Authentication

<ParamField header="Partner-App-Key" type="string" required>
  Your partner app key.
</ParamField>

<ParamField header="X-HSPay-Signature" type="string" required>
  Base64-encoded Ed25519 signature of the sign data.
</ParamField>

<ParamField header="X-HSPay-Timestamp" type="string" required>
  Unix timestamp (seconds) of the request. Must be within 60 seconds of server time.
</ParamField>

## Query Parameters

<ParamField query="token" type="string">
  Filter by token symbol (e.g., `USDT`, `USDC`, `VND`).
</ParamField>

<ParamField query="change_type" type="integer">
  Filter by change type. `1` = Deposit, `2` = Withdraw, `3` = Compensate, `4` = Convert out, `5` = Convert in.
</ParamField>

<ParamField query="page" type="integer">
  Page number for pagination.
</ParamField>

<ParamField query="page_size" type="integer">
  Results per page. Default `20`, max `100`.
</ParamField>

## Log Fields

| Field | Type | Notes |
|---|---|---|
| `id` | integer | Fund log ID |
| `partner_fund_id` | integer | The fund (partner + token) this change applies to |
| `change_type` | integer | `1` = Deposit, `2` = Withdraw, `3` = Compensate, `4` = Convert out, `5` = Convert in |
| `change_amount` | string | Net amount applied to the balance, signed |
| `fee` | string | Fee charged on this change |
| `pre_balance` | string | Balance before the change |
| `post_balance` | string | Balance after the change |
| `metadata` | object | What caused the change — see [Metadata](#metadata) |
| `caused_at` | object | `{ seconds, nanos }` timestamp |

<Warning>
  `change_amount` is the **net** amount. The gross amount is `change_amount` + `fee`. A 5,000,000 VND bank transfer with a 5,000 VND deposit fee is recorded as `change_amount` `4995000` and `fee` `5000` — reconcile against the gross, not the net.
</Warning>

## Metadata

Every log's `metadata` carries:

| Field | Notes |
|---|---|
| `source` | What caused the change: `fiat_deposit`, `crypto_deposit`, `withdraw`, `crypto_payout`, `compensate`, or `convert` |
| `reference_id` | Reference for the causing event |
| `reason` | Present only when set |

<Note>
  `source` is finer-grained than `change_type`. A VND bank deposit and an on-chain stablecoin deposit are both `change_type` `1` — only `source` (`fiat_deposit` vs `crypto_deposit`) tells them apart. The same holds for `withdraw` and `crypto_payout`, which are both `change_type` `2`. **Branch on `source`, not on `change_type`.**
</Note>

Each source adds its own fields:

### `fiat_deposit`

A VND transfer into a [deposit account](/guides/partner-prefunding#vnd-deposit-accounts).

| Field | Notes |
|---|---|
| `provider` | Provider holding the deposit account, e.g. `GPAY` |
| `account_number` | The deposit account the money arrived in |
| `transaction_id` | Provider transaction ID |
| `bank_transaction_id` | Bank transaction ID |
| `bank_trace_id` | Bank trace number. Empty when the provider does not send it. |
| `sender_name` | Name on the sending account |
| `sender_account` | Sending bank account number |
| `sender_bank_bin` | BIN code of the sending bank |
| `transfer_content` | Transfer note the sender wrote |
| `paid_at` | When the transfer was paid. Empty when the provider does not send it. |

### `crypto_deposit`

An on-chain deposit to one of your [deposit addresses](/api-reference/funds/list-deposit-addresses).

| Field | Notes |
|---|---|
| `chain_id` | Chain the deposit arrived on |
| `tx_hash` | On-chain transaction hash |

### `withdraw`, `crypto_payout`, `compensate`

| Field | Notes |
|---|---|
| `order_id` | The order that caused the change |

### `convert`

One [conversion](/guides/partner-prefunding#converting-between-stablecoins) writes two logs — convert out and convert in — sharing a single `convert_ref`.

| Field | Notes |
|---|---|
| `convert_ref` | Pairs the two legs of the conversion |
| `from_token` | Source stablecoin |
| `to_token` | Target stablecoin |
| `rate` | Conversion rate — always `1` |
