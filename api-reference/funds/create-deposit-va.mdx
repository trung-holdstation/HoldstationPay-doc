---
title: "Create VND Deposit Account"
api: "POST https://pay-api.holdstation.com/partners/funds/deposit-vas"
description: "Open a new VND deposit account for receiving bank transfers into the fund."
---

Opens a **new** VND deposit account. Holdstation Pay sets the provider for each partner.

A partner can hold several deposit accounts at once — use them to separate flows, counterparties, or reconciliation streams, and read each one's credits with [List Deposit Account Transactions](/api-reference/funds/list-deposit-va-transactions).

Any bank transfer to any of these accounts credits the same VND fund, and the [Balance Change Webhook](/guides/webhooks/balance-change-webhook) reports it.

<Warning>
  Every call opens a **new account with a new account number** — it is not idempotent and does not return an existing one. Store the `id` and `account_number` it returns; call [List VND Deposit Accounts](/api-reference/funds/list-deposit-vas) to retrieve accounts you already hold, rather than calling this endpoint again.
</Warning>

See [Prefunding Offramp Flow → VND Deposit Accounts](/guides/partner-prefunding#vnd-deposit-accounts) for the workflow.

<Note>
  This endpoint takes no request body.
</Note>

## Authentication

<ParamField header="Partner-App-Key" type="string" required>
  Your partner app key.
</ParamField>

<ParamField header="X-HSPay-Signature" type="string" required>
  Base64-encoded Ed25519 signature of the sign data.
</ParamField>

<ParamField header="X-HSPay-Timestamp" type="string" required>
  Unix timestamp (seconds) of the request. Must be within 60 seconds of server time.
</ParamField>

## Response Fields

| Field | Type | Notes |
|---|---|---|
| `id` | string | Deposit account ID — use it on the close and transactions endpoints |
| `provider` | string | Provider holding the account, e.g. `GPAY` |
| `account_number` | string | Bank account number to transfer VND to |
| `account_name` | string | Account holder name the sender's bank shows |
| `bank_code` | string | Bank the account is on, e.g. `BIDV` |
| `status` | string | `ACTIVE` or `CLOSED` |
| `created_at` | string | ISO 8601 timestamp |
