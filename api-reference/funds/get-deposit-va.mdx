---
title: "Get VND Deposit Account"
api: "GET https://pay-api.holdstation.com/partners/funds/deposit-vas/{va_id}"
description: "Retrieve one VND deposit account by ID, active or closed."
---

Returns one of the partner's VND deposit accounts, active or closed.

Use [List VND Deposit Accounts](/api-reference/funds/list-deposit-vas) when you don't have the ID to hand. To open a new account, see [Create VND Deposit Account](/api-reference/funds/create-deposit-va).

<Note>
  An ID that belongs to another partner returns `404`, the same as an unknown ID. A malformed `va_id` returns `400`.
</Note>

## Authentication

<ParamField header="Partner-App-Key" type="string" required>
  Your partner app key.
</ParamField>

<ParamField header="X-HSPay-Signature" type="string" required>
  Base64-encoded Ed25519 signature of the sign data.
</ParamField>

<ParamField header="X-HSPay-Timestamp" type="string" required>
  Unix timestamp (seconds) of the request. Must be within 60 seconds of server time.
</ParamField>

## Path Parameters

<ParamField path="va_id" type="string" required>
  Deposit account ID.
</ParamField>

## Response Fields

| Field | Type | Notes |
|---|---|---|
| `id` | string | Deposit account ID |
| `account_number` | string | Bank account number to transfer VND to |
| `account_name` | string | Account holder name the sender's bank shows |
| `bank_id` | integer | ID of the bank the account is on |
| `bank` | object | Bank details — `id`, `bin_code`, `short_name`, `bank_name`, `image` |
| `status` | string | `ACTIVE` or `CLOSED` |
| `created_at` | string | ISO 8601 timestamp |
