---
title: "Get VND Deposit Account"
api: "POST https://pay-api.holdstation.com/partners/funds/deposit-vas"
description: "Get the partner's VND deposit account, opening one if there is none."
---

Returns the partner's VND deposit account, opening one if there is none. Holdstation Pay sets the provider for each partner. **Calling it again returns the same account** — it is safe to retry.

Any bank transfer to this account credits the partner's VND fund, and the [Balance Change Webhook](/guides/webhooks/balance-change-webhook) reports it.

See [Prefunding Offramp Flow → VND Deposit Accounts](/guides/partner-prefunding#vnd-deposit-accounts) for the workflow.

<Note>
  This endpoint takes no request body.
</Note>

## Authentication

<ParamField header="Partner-App-Key" type="string" required>
  Your partner app key.
</ParamField>

<ParamField header="X-HSPay-Signature" type="string" required>
  Base64-encoded Ed25519 signature of the sign data.
</ParamField>

<ParamField header="X-HSPay-Timestamp" type="string" required>
  Unix timestamp (seconds) of the request. Must be within 60 seconds of server time.
</ParamField>

## Response Fields

| Field | Type | Notes |
|---|---|---|
| `id` | string | Deposit account ID — use it on the close and transactions endpoints |
| `provider` | string | Provider holding the account, e.g. `GPAY` |
| `account_number` | string | Bank account number to transfer VND to |
| `account_name` | string | Account holder name the sender's bank shows |
| `bank_code` | string | Bank the account is on, e.g. `BIDV` |
| `status` | string | `ACTIVE` or `CLOSED` |
| `created_at` | string | ISO 8601 timestamp |
