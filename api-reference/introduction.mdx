## Base URL

```
https://pay-api.holdstation.com
```

## Authentication

Every endpoint requires three headers — `Partner-App-Key`, `X-HSPay-Signature`, and `X-HSPay-Timestamp` — and requests must come from a whitelisted IP address. See [Authentication](/authentication) for details.

| Status Code | Cause |
|-------------|-------|
| `401` | Missing or invalid API key, or an invalid signature |
| `403` | Source IP is not whitelisted |

## Error Responses

All endpoints return a consistent error format:

```json
{
  "error": "string",
  "error_code": "string",
  "message": "string",
  "detail": "string"
}
```

| Status Code | Description          |
|-------------|----------------------|
| `200`       | Success              |
| `400`       | Bad Request          |
| `401`       | Unauthorized         |
| `500`       | Internal Server Error|

## Response Wrapper

Successful responses are wrapped in a standard envelope:

```json
{
  "message": "string",
  "data": { ... }
}
```
