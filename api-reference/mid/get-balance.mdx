---
title: "Get MID Balance"
api: "POST https://pay-api.holdstation.com/partners/mid/balance"
description: "Get the balance of the partner's Merchant ID (MID) account."
---

Get the VND prefund balance for the partner's assigned HPay merchant (MID).

## Authentication

<ParamField header="Partner-App-Key" type="string" required>
  Your partner app key.
</ParamField>

<ParamField header="X-HSPay-Signature" type="string" required>
  Base64-encoded Ed25519 signature of the sign data.
</ParamField>

<ParamField header="X-HSPay-Timestamp" type="string" required>
  Unix timestamp (seconds) of the request. Must be within 60 seconds of server time.
</ParamField>

<Note>
  This endpoint takes no request body.
</Note>

## Response Fields

| Field | Type | Notes |
|---|---|---|
| `id` | integer | Fund record ID |
| `partner_id` | string | The partner that owns the balance |
| `token` | string | Token symbol — `VND` |
| `balance` | string | Current balance as a decimal string |
| `fund_type` | integer | `1` = crypto, `2` = fiat |
| `updated_at` | string | ISO 8601 timestamp |
