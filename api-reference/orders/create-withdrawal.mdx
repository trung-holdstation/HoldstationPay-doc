---
title: "Create Withdrawal"
api: "POST https://pay-api.holdstation.com/partners/orders/withdrawal"
description: "Create a new offramp order for a user to sell tokens and receive VND via bank transfer."
---

## Overview

Partner uses this API to create a new withdrawal order. See [Offramp Flow](/guides/offramp-flow) for the full integration guide.

## Authentication

<ParamField header="Partner-App-Key" type="string" required>
  Your partner app key.
</ParamField>

<ParamField header="X-HSPay-Signature" type="string" required>
  Base64-encoded Ed25519 signature of the sign data.
</ParamField>

<ParamField header="X-HSPay-Timestamp" type="string" required>
  Unix timestamp (seconds) of the request. Must be within 60 seconds of server time.
</ParamField>

<ParamField body="amount" type="string" required>
  Amount to withdraw in USD (or VND if `currency=vnd`).
</ParamField>

<ParamField body="currency" type="string" required>
  Currency of the amount: `vnd` or `usd`.
</ParamField>

<ParamField body="chain_id" type="integer" required>
  Blockchain network ID. See [List Tokens](/api-reference/tokens/list-tokens).
</ParamField>

<ParamField body="token_address" type="string" required>
  Token contract address. See [List Tokens](/api-reference/tokens/list-tokens).
</ParamField>

<ParamField body="payment_info" type="object" required>
  User's bank account details to receive VND.

  <Expandable title="payment_info">
    <ParamField body="bank_id" type="integer" required>
      Bank ID. See [List Banks](/api-reference/banks/list-banks).
    </ParamField>
    <ParamField body="full_name" type="string" required>
      Full name of the account holder.
    </ParamField>
    <ParamField body="account_type" type="integer" required>
      `1` = Bank account number, `2` = ATM card number.
    </ParamField>
    <ParamField body="account_number" type="string" required>
      Bank account number.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="callback" type="string" required>
  HTTPS URL to receive order status webhook notifications.
</ParamField>

<ParamField body="reference_no" type="string">
  Optional. Use this to map the Holdstation Pay order to your internal order. Must be unique per partner.
</ParamField>

<ParamField body="buffer" type="number" required>
  Optional buffer rate override (fractional). Effective buffer = max(override, configured). Example: `0.005` = 0.5%.
</ParamField>

<ParamField body="refund_address" type="string">
  Optional. Wallet on `chain_id` to receive the crypto back if the bank payout is rejected after the crypto has been received — the order then becomes **Refunded** (state `6`). Must match the chain's address format. **Not supported for native tokens.** When set, it is appended to the end of the signed message. See [Order Flow](/guides/order-flow#order-states).
</ParamField>

<ParamField body="kyc_id" type="string">
  Partner customer KYC id. The order is rejected if this is missing or does not match a registered KYC record. See [Partner Customer KYC](/guides/partner-customer-kyc/overview).
</ParamField>
