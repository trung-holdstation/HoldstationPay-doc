---
title: "Get Exchange Rate"
api: "GET https://pay-api.holdstation.com/api/v1/exchange/rate"
description: "Retrieve the buy and sell exchange rates between USD and VND."
---

## Overview

Partners use this API to retrieve the buy and sell exchange rates between USD/VND in the system.

## Authentication

<ParamField header="Partner-App-Key" type="string" required>
  Your partner app key.
</ParamField>

<ParamField header="X-HSPay-Signature" type="string" required>
  Base64-encoded Ed25519 signature of the sign data.
</ParamField>

<ParamField header="X-HSPay-Timestamp" type="string" required>
  Unix timestamp (seconds) of the request. Must be within 60 seconds of server time.
</ParamField>

<ParamField query="original" type="boolean">
  Set to `true` to get the original rate before applying fees.
</ParamField>

<ResponseExample>
```json 200
{
  "message": "success",
  "data": {
    "rate": {
      "buy": "25850",
      "sell": "25750"
    }
  }
}
```

```json 400
{
  "error": "invalid request",
  "error_code": "BAD_REQUEST",
  "message": "Invalid parameters"
}
```
</ResponseExample>
